# backendshopstore

## Описание проекта

`backendshopstore` — это бэкенд-приложение, разработанное с использованием FastAPI, предназначенное для управления интернет-магазином. Проект включает в себя функциональность для работы с пользователями, продуктами, заказами, категориями, регионами и менеджерами. Особое внимание уделено использованию материализованных представлений (Materialized Views) и индексации для оптимизации производительности базы данных.

## Основные возможности

*   **Аутентификация и авторизация:** Безопасный доступ к API с использованием JWT.
*   **Управление продуктами:** Добавление, изменение, удаление и просмотр товаров.
*   **Управление заказами:** Создание и отслеживание заказов.
*   **Управление пользователями:** Регистрация и управление данными клиентов и менеджеров.
*   **Категории и регионы:** Организация товаров по категориям и управление регионами доставки.
*   **Материализованные представления:** Использование материализованных представлений для ускорения сложных запросов.
*   **Кэширование:** Интеграция с Redis для кэширования данных и повышения производительности.
*   **Фоновые задачи:** Использование Celery для обработки длительных операций.

## Используемые технологии

*   **Python 3.11+**
*   **FastAPI:** Высокопроизводительный веб-фреймворк для создания API.
*   **Uvicorn:** ASGI-сервер для запуска FastAPI-приложения.
*   **SQLAlchemy:** ORM (Object-Relational Mapper) для взаимодействия с базой данных.
*   **Alembic:** Инструмент для миграции базы данных.
*   **PostgreSQL:** Реляционная база данных.
*   **Asyncpg:** Асинхронный драйвер PostgreSQL.
*   **Redis:** Хранилище данных в памяти, используемое для кэширования и брокера сообщений Celery.
*   **Celery:** Распределенная очередь задач для обработки фоновых операций.
*   **PyJWT & Passlib:** Для реализации аутентификации на основе JWT и хеширования паролей.
*   **Pydantic:** Для валидации данных и управления настройками.
*   **Pytest:** Фреймворк для тестирования.
*   **Ruff & Black:** Инструменты для форматирования кода и линтинга.

## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone <URL_ВАШЕГО_РЕПОЗИТОРИЯ>
cd shop_store_backend/shop_store_project
```

### 2. Создание и активация виртуального окружения

Рекомендуется использовать `venv` или `Poetry` для управления зависимостями.

**Использование `venv`:**

```bash
python -m venv .venv
# Для Windows
.venv\Scripts\activate
# Для macOS/Linux
source .venv/bin/activate
```

**Использование `Poetry` (если установлен):**

```bash
poetry install
poetry shell
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
# Если используете Poetry, зависимости будут установлены командой poetry install
```

### 4. Настройка переменных окружения

Создайте файл `.env` в корневой директории проекта (`shop_store_project/`) на основе файла `.env-test` или следующего шаблона:

```dotenv
MODE="LOCAL"

DB_HOST="localhost"
DB_PORT=5432
DB_NAME="your_db_name"
DB_USER="your_db_user"
DB_PASS="your_db_password"

REDIS_HOST="localhost"
REDIS_PORT=6379

JWT_SECRET_KEY="your_super_secret_jwt_key"
JWT_ALGORITHM="HS256"
ACCESS_TOKEN_EXPIRE_MINUTES=30
```

Замените значения-заполнители (`your_db_name`, `your_db_user`, `your_db_password`, `your_super_secret_jwt_key`) на свои собственные.

### 5. Настройка базы данных

Убедитесь, что у вас установлен и запущен PostgreSQL и Redis.

Примените миграции базы данных с помощью Alembic:

```bash
alembic upgrade head
```

### 6. Запуск приложения

```bash
uvicorn src.main:app --reload --host 0.0.0.0 --port 8000
```

Приложение будет доступно по адресу `http://localhost:8000`.
Документация API (Swagger UI) будет доступна по адресу `http://localhost:8000/docs`.

### 7. Запуск Celery Worker (для фоновых задач)

В отдельном терминале, находясь в активированном виртуальном окружении:

```bash
celery -A src.tasks.celery_app worker --loglevel=info
```

## Тестирование

Для запуска тестов используйте `pytest`:

```bash
pytest
```
